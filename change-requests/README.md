# Change requests

Every change to this catalogue lands through a change request. One CR per PR.

| CR | Scope | State |
|---|---|---|
| `CR-IS-CAT-03A` | Foundation: method, pointer, schema projection, CI. No records. | implemented |
| `CR-IS-CAT-03B` | Taxonomy: ratify the four classification axes | pending |
| `CR-IS-CAT-03C` | Documentation standard: per-record template and evidence checklist | pending |
| `CR-IS-CAT-03D` | Population: admit the first records | pending, gated on 03B and 03C |
| `CR-IS-CAT-03E` | Integration: reference hardening, conformance reporting, governance handover | pending |
